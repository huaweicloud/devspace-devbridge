# Client-Side Version Support

This page describes the support status of each DevBridge CLI client version. The client side includes only the DevBridge command-line tool (CLI).

## Support status

- **Supported**: still maintained, with feature updates and bug fixes. Use the latest version where possible.
- **Planned EOS**: an end-of-support date has been announced. After that date, maintenance stops; upgrade before then.
- **EOS**: support has ended. No further feature updates or bug fixes are provided; upgrade to a supported version.

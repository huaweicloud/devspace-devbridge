# 端侧版本维护清单

本页说明 DevBridge CLI 客户端各版本的支持状态。端侧（客户端）仅包含 DevBridge 命令行工具（CLI）。

## 支持状态说明

- **支持中**：仍在维护，提供功能更新与问题修复，建议使用最新版本。
- **计划 EOS**：已公布停止支持日期，到期后将不再维护，请在此之前完成升级。
- **已 EOS**：已停止支持，不再提供功能更新与问题修复，请尽快升级到受支持的版本。

| ------------- | ------ |
| 0.3.0-release | 支持中 |
| 0.2.2-release | 支持中 |
| 0.2.1-release | 已 EOS |
| 0.2.0-release | 已 EOS |
| 0.1.9-release | 已 EOS |
| 0.1.0         | 已 EOS |

## 计划 EOS

目前暂无计划 EOS 的版本。

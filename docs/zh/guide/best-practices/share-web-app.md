# 开发并分享一个 Web 应用

<p class="lead">用自然语言驱动码道（CodeArts）代码智能体开发一个 Web 版个人博客，监听 8080 端口，再通过 DevBridge 隧道把它变成无需登录即可浏览的公网 HTTPS 地址。</p>

## 场景与目的

实践在华为云 AI 开发者空间体验版中完成，全程对话驱动、零手动编码，大约 30 分钟：

- 用一句提示词让码道代码智能体开发并启动一个 Web 版个人博客。
- 通过 DevBridge 开发隧道把云端 8080 端口的服务暴露为公网 HTTPS 地址。
- 为隧道配置匿名访问，让其他用户无需登录即可浏览博客。
- 体验结束后清理隧道及全部资源，避免残留。

这套流程适合想快速体验“AI 辅助开发 → 公网分享 → 资源清理”闭环的个人开发者、高校学生和 AI 开发新手：无需配置公网 IP，也不需要开放任何入站端口。

# Develop and share a web app

<p class="lead">Drive the CodeArts coding agent with natural language to build a personal blog web app listening on port 8080, then expose it publicly over HTTPS through a DevBridge tunnel so visitors can browse it without signing in.</p>

## Scenario and goal

The practice runs in the Huawei Cloud AI DevSpace experience edition and takes about 30 minutes, with no manual coding:

- Prompt the CodeArts coding agent to build and start a personal blog web app.
- Expose the service on port 8080 through a DevBridge tunnel as a public HTTPS URL.
- Configure anonymous access so other users can browse the blog without signing in.
- Clean up the tunnel and all resources when you're done.

It suits individual developers, students, and newcomers who want to experience the end-to-end workflow of AI-assisted development, public sharing, and cleanup. No public IP or inbound port is required.

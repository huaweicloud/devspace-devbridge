# Develop and share a web app

<p class="lead">Drive the CodeArts coding agent with natural language to build a web blog listening on port 8080, then turn it into a public HTTPS site that visitors can browse without signing in, using a DevBridge tunnel.</p>

## Scenario and goal

The practice runs in the Huawei Cloud AI DevSpace experience edition and takes about 30 minutes, with no manual coding:

- Prompt the CodeArts coding agent to build and start a web personal blog.
- Expose the service on port 8080 through a DevBridge tunnel as a public HTTPS URL.
- Configure anonymous access so other users can browse the blog without signing in.
- Clean up the tunnel and all resources when you're done.

It suits individual developers, students, and newcomers who want to experience the full loop of AI-assisted development, public sharing, and cleanup. No public IP or inbound port is required.

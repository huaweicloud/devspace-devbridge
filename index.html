快速入门

创建并托管开发隧道

使用 guacamole CLI 将本机服务安全地开放给远程客户端，并控制谁可以访问。

预计用时：10 分钟 · 适用于 CLI 1.0.0
你将完成什么

安装并登录 CLI，启动一条转发本地 8080 端口的隧道，然后从另一台设备连接该隧道。

本文内容

  • 安装并验证 CLI
  • 使用交互登录或 AK/SK 登录
  • 托管一个本地 Web 服务
  • 从远程客户端连接隧道

功能特性

DevBridge CLI 覆盖开发隧道从创建到连接的完整工作流：

隧道管理创建、查看、更新、删除和选择默认隧道。
端口管理为一条隧道配置多个 HTTP、HTTPS 或自动识别端口。
Host 模式把本机一个或多个端口转发到 DevBridge。
Connect 模式从远程客户端连接隧道并建立本地端口映射。
多种认证支持交互登录、AK/SK 和临时 Security Token。
稳定连接安全保存凭证，网络中断后自动重新连接。

安装

使用 install.sh 安装 CLI。默认可执行文件目录是 ~/.huawei/bin，默认配置目录是 ~/.huawei/devbridge。

Shell
bash install.sh -v 1.0.0

将指定版本安装到 ~/.huawei/bin。

Shell
bash install.sh -d /path/to/bin -v 1.0.0

-d 指定 CLI 可执行文件的安装目录。

Shell
bash install.sh -u https://downloads.example.com/devbridge -v 1.0.0

-u 指定安装包下载源，适用于内网镜像或测试仓库。

Shell
bash install.sh -d ./bin -s

-s 以静默模式安装，只保留必要的结果和错误输出。

安装完成后，将默认目录加入 PATH 并检查版本：

Shell
export PATH="$HOME/.huawei/bin:$PATH"
guacamole --version
持久化 PATH

把上述 export 写入 ~/.bashrc 或 ~/.zshrc，重新打开终端后即可直接运行 guacamole。

登录

托管或连接隧道前必须先登录。个人开发环境优先使用交互登录：

Shell
guacamole auth login

CLI 会引导你完成身份认证，并把登录凭据保存到受保护的凭证存储中。

自动化环境可以使用 AK/SK；临时凭证还应提供 Security Token：

Shell
# 长期 AK/SK
guacamole auth login \
  --access-key "$DEVBRIDGE_ACCESS_KEY" \
  --secret-key "$DEVBRIDGE_SECRET_KEY"

# 临时 AK/SK
guacamole auth login \
  --access-key "$DEVBRIDGE_ACCESS_KEY" \
  --secret-key "$DEVBRIDGE_SECRET_KEY" \
  --security-token "$DEVBRIDGE_SECURITY_TOKEN"

检查当前身份或清除本地登录状态：

Shell
guacamole auth status
guacamole auth logout
不要把密钥写进命令历史

在自动化环境中通过受保护的环境变量或密钥服务注入 AK、SK 和 Security Token，不要把真实值直接写入脚本或仓库。

Host：托管本地服务

下面的示例先在本机启动一个测试服务，再创建一条有效期为 8 小时的临时隧道并托管端口 8080。

1. 启动本地服务

终端 1
python3 -m http.server 8080

2. 托管端口

为方便阅读，后续示例使用 g 作为 guacamole 的别名：

终端 2
alias g=guacamole
g host -p 8080 -d "Local web server" -e 8

未指定隧道 ID 时，host 会创建临时隧道、配置端口并立即建立宿主连接。成功后输出类似：

输出
Created tunnel: km5q7d2a
Hosting port 8080
Tunnel URL: https://km5q7d2a.cn-north-4-bridge.myhuaweicloud.com
Ready to accept connections
Auto reconnect: enabled

保持该进程运行。网络短暂中断时 CLI 会自动重连；结束进程会停止转发，但已创建的隧道仍按有效期保留。

Connect：连接隧道

在另一台已经安装并登录 CLI 的设备上，使用 Host 输出的隧道 ID 建立连接：

远程终端
alias g=guacamole
g connect km5q7d2a

Connect 模式读取隧道的端口配置，并在本机建立对应映射。输出类似：

输出
Connected to tunnel: km5q7d2a
Forwarding localhost:8080 -> tunnel port 8080
Auto reconnect: enabled

现在访问 http://localhost:8080，即可连接 Host 设备上的本地服务。按 Ctrl+C 停止当前连接。

两种访问方式

Web 端口可以使用 Host 输出的 URL；需要本地端口映射或非浏览器客户端时使用 connect。受保护端口会由 CLI 自动申请并使用 connect 凭证。

隧道管理

持久隧道适合需要重复 Host、保留相同隧道 ID 或预先配置多个端口的场景。

本节使用 g 简写；新终端中先执行 alias g=guacamole，也可以把所有 g 替换为 guacamole。

创建隧道

Shell
g create frontend -d "Frontend preview" -e 24

frontend 是隧道名称，-d 设置描述，-e 设置有效期小时数。默认 72 小时，允许范围为 1 到 720 小时。

查询隧道

Shell
# 列出当前工作空间的有效隧道
g list

# 输出适合脚本处理的 JSON
g list -j

# 查看单条隧道
g show <tunnelId>

更新和删除

Shell
g update <tunnelId> -n "frontend" -d "Frontend preview" -e 48
g delete <tunnelId>
g delete-all

delete-all 删除当前工作空间中的全部隧道，应在 CLI 二次确认后执行。删除隧道也会删除它的端口配置。

签发专用令牌

Shell
g token <tunnelId> -s host
g token <tunnelId> -s connect

通常由 host 和 connect 自动获取令牌。只有集成其他客户端时才需要手动签发；每次执行都会返回新令牌。

端口管理

一条隧道可以开放多个端口。未配置的端口默认不能访问。

Shell
# 创建受保护的 HTTP 端口
g port create <tunnelId> -p 8080 --protocol http -d "Web API"

# 创建允许匿名访问的自动识别端口
g port create <tunnelId> -p 3000 --protocol auto -a

# 查询端口
g port list <tunnelId>
g port show <tunnelId> -p 8080

# 更新或删除端口
g port update <tunnelId> -p 8080 -d "Updated Web API" -a
g port delete <tunnelId> -p 8080
参数含义
-p, --port本地或隧道端口，范围为 1 到 65535。
--protocolhttp、https 或 auto。
-d, --description便于识别端口用途的描述。
-a, --allow-anonymous允许不登录的访问者连接该端口。
匿名访问默认关闭

只有明确需要公开的测试页面才使用 -a。管理后台、调试端点和包含用户数据的服务应保持受保护状态。

设置默认隧道

频繁操作同一条隧道时，可以把它设置为当前默认隧道：

Shell
g set <tunnelId>

# 后续命令可以省略 tunnelId
g port list
g host -p 8080

# 清除默认隧道
g unset

默认隧道只影响本机 CLI 上下文，不会修改隧道归属或其他用户的设置。

远程端口转发

Host 模式

Host 模式运行在服务所在设备，把本地端口注册到现有隧道：

Shell
# 托管一个端口
g host <tunnelId> -p 8080

# 同时托管多个端口
g host <tunnelId> -p 8080 -p 3000

# 创建临时隧道并立即托管
g host -p 8080 -d "Temporary preview" -e 8

Connect 模式

Connect 模式运行在访问设备，连接隧道并为可用端口建立本地映射：

Shell
g connect <tunnelId>

Host 和 Connect 都是长运行命令。保持进程运行即可持续转发；网络恢复后 CLI 会自动重连。

认证方式

方式适用场景命令
交互登录开发人员日常使用guacamole auth login
AK/SK固定服务账号或自动化任务--access-key + --secret-key
临时 AK/SK短期任务和动态授权AK/SK + --security-token

交互登录最适合个人使用；自动化环境优先使用短期凭证，降低凭证泄露后的影响范围。

凭证与自动重连

  • 登录成功后，CLI 将凭证写入受保护的本地凭证存储；命令输出不会回显 SK 或完整令牌。
  • auth status 只显示当前身份、认证方式和有效状态。
  • auth logout 清除 CLI 保存的登录凭证，不会删除隧道。
  • Host 和 Connect 在网络短暂中断后自动重连，不需要重新创建隧道。
  • 凭证过期或权限被撤销时，CLI 停止重试并提示重新登录。

目录说明

目录用途
~/.huawei/bin默认 CLI 安装目录。可以通过安装参数 -d 修改。
~/.huawei/devbridgeCLI 配置、当前默认隧道和运行状态目录。

不要把配置目录复制到其他用户或提交到代码仓库。迁移设备时应在新设备重新登录。

命令速查

命令用途
guacamole auth login登录 DevBridge。
g create <name>创建持久隧道。
g list [-j]列出有效隧道，可输出 JSON。
g show <tunnelId>查看隧道详情。
g update <tunnelId>更新名称、描述或有效期。
g delete <tunnelId>删除一条隧道。
g port create给隧道添加端口。
g set <tunnelId>设置默认隧道。
g host从服务设备托管本地端口。
g connect <tunnelId>从访问设备连接隧道。

使用 guacamole --help 或任意命令后的 --help 查看当前版本支持的全部参数。

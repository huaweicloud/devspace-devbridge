# DevBridge SSH 隧道一键安装指南

## 这是什么

在华为云 ECS 上**一行命令**完成以下全部操作：

1. 安装 DevBridge CLI
2. 安装 SSH 服务（Windows 自动装 OpenSSH Server，Linux 自带）
3. 用 API Key 登录 DevBridge
4. 创建隧道，暴露 SSH 端口 22
5. 加密存储 API Key（AES-256-GCM + PBKDF2-SHA256）
6. 配置开机自启（Linux 用 systemd，Windows 用计划任务）
7. 启动隧道并验证

**安全组不需要任何入方向规则**，DevBridge 通过出方向隧道连接，SSH 流量走隧道不走公网端口。

---

## 前置条件

| 条件 | 说明 |
|------|------|
| 华为云 ECS | Linux 或 Windows 均可，需要有公网出方向访问能力（EIP 或 NAT 网关） |
| DevBridge API Key | 在 https://devstation.connect.huaweicloud.com/space/devbridge?tab=apikey 获取，格式 `devbridge_xxxxxxxx` |
| 安全组 | 出方向放行 TCP 443（HTTPS），入方向**不需要开任何端口** |

## Linux 一键安装

在 ECS 上以 root 用户执行：

```bash
curl -fsSL https://raw.gitcode.com/anruostyle/devbridge-ssh-setup/raw/main/setup-devbridge-ssh.sh | bash -s -- --api-key <你的API_KEY>
```

> 💡 默认加密存储 API Key。如需明文存储，末尾加 `--plaintext`。

**示例：**

```bash
curl -fsSL https://raw.gitcode.com/anruostyle/devbridge-ssh-setup/raw/main/setup-devbridge-ssh.sh | bash -s -- --api-key devbridge_xxxxxxxxxxxxxxxxxxxxxxxx
```

执行完成后会看到类似输出：

```
============================================================
   DevBridge SSH Tunnel 安装完成
============================================================

 隧道 ID:    p4f36563
 SSH 端口:   22
 有效期:     720h (剩余 < 24h 自动续期)
 服务名:     devbridge-ssh.service
 运行身份:   root
 API Key:    已加密存储 (AES-256-GCM + PBKDF2)

 从另一台设备连接此 ECS 的 SSH：
   devbridge connect p4f36563
   ssh root@localhost
============================================================
```


## 如何通过隧道连接 ECS

安装完成后，在**你的本地电脑**（不是 ECS）上执行以下步骤。

### 第一步：安装 DevBridge CLI

**Linux / macOS：**

```bash
curl -fsSL https://tools-artifact.developer.huaweicloud.com/sharedata/devbridge/install.sh | bash
```

安装完成后，CLI 在 `~/.huawei/bin/devbridge`。验证安装：

```bash
devbridge version
```

如果提示 `command not found`，说明 PATH 未生效，手动添加：

```bash
export PATH="$HOME/.huawei/bin:$PATH"
devbridge version
```

> 💡 建议把 `export PATH="$HOME/.huawei/bin:$PATH"` 加到 `~/.bashrc` 或 `~/.zshrc`，避免每次手动设置。

**Windows（PowerShell）：**

```powershell
irm https://tools-artifact.developer.huaweicloud.com/sharedata/devbridge/install.ps1 | iex
```

### 第二步：登录 DevBridge

用同一个 API Key 登录（和 ECS 上安装时用的相同）：

```bash
devbridge auth login --api-key <你的API_KEY>
```

验证登录状态：

```bash
devbridge auth status
```

### 第三步：找到要连接的隧道

列出所有隧道：

```bash
devbridge list
```

输出类似：

```
Tunnel ID    Name                        Status    Ports   HostConnections
p4f36563     ecs-ssh-web01-a1b2c3d4      active    22      1
p8e24791     ecs-rdp-win02-e5f6a7b8      active    3389    1
```

- **Tunnel ID**：连接时需要用这个
- **Name**：格式 `ecs-ssh-<hostname>-<machine-id前8位>`，可以认出是哪台 ECS
- **Ports**：22 = Linux SSH，3389 = Windows RDP

如果隧道很多认不出来，去 ECS 上看配置文件里的隧道 ID：

```bash
# Linux ECS 上
cat ~/.huawei/devbridge/ssh-tunnel.conf | grep TUNNEL_ID

# Windows ECS 上
type %USERPROFILE%\.huawei\devbridge\ssh-tunnel.json | findstr TunnelId
```

### 第四步：连接隧道

```bash
devbridge connect <隧道ID>
```

这会在本地建立端口转发。**请务必看输出中的端口映射信息**，例如：

```
# Linux ECS:
Forwarding localhost: 43621 -> tunnel port: 22 (port 22 in use)

# Windows ECS:
Forwarding localhost: 43621 -> tunnel port: 3389
```

- Linux ECS（端口 22）：如果本地 22 端口空闲，映射到 `localhost:22`；否则自动映射到其他端口（如 `localhost:43621`）
- Windows ECS（端口 3389）：自动映射到本地某端口（如 `localhost:43621`），用 `mstsc` 连接

### 第五步：连接 ECS

**Linux ECS（SSH）：**

```bash
# 如果映射到 22 端口（本地 22 空闲）：
ssh root@localhost

# 如果映射到其他端口（看步骤 4 的输出）：
ssh root@localhost -p 43621  # 用实际输出的端口号
```

**Windows ECS（RDP）：**

```bash
# 看步骤 4 的输出中的端口映射，如 localhost:43621 -> tunnel port: 3389
# 用映射后的本地端口连接远程桌面：
mstsc /v:localhost:43621
```

输入 ECS 的密码即可登录。

## 通过隧道传输文件（SFTP / SCP）

Linux ECS 的 SSH 隧道建立后，SFTP 和 SCP **自动可用**，无需额外配置——它们和 SSH 走同一个端口 22。

> 以下命令中的端口号与 SSH 连接时一致：本地 22 空闲用默认端口，被占用时用 `devbridge connect` 输出的映射端口。
>
> Windows ECS 走 RDP 隧道（3389），不适用 SFTP/SCP。文件传输可通过 RDP 剪贴板复制，或在隧道中额外添加 22 端口。

### SFTP 交互式文件传输

```bash
# Linux ECS（端口 22 空闲时）
sftp root@localhost

# 端口被映射到其他端口时
sftp -P 43621 root@localhost
```

进入 SFTP 后常用命令：

```
put localfile /remote/path/       # 上传文件
get /remote/file /local/path/     # 下载文件
ls / cd / pwd                     # 浏览远程目录
lls / lcd / lpwd                  # 浏览本地目录
```

### SCP 单文件传输

```bash
# 上传（本地 → ECS）
scp -P 43621 localfile.txt root@localhost:/remote/path/
# 下载（ECS → 本地）
scp -P 43621 root@localhost:/remote/file.txt /local/path/
```

> 💡 SCP 的端口参数是大写 `-P`，SSH/SFTP 的端口参数是小写 `-p`，注意区分。

## 常见问题

### Q: 安装后 SSH 连不上？

检查以下几点：

1. **ECS 有没有公网出方向能力？** DevBridge 需要出方向访问 `bridge.developer.myhuaweicloud.com:443`，ECS 必须有 EIP 或 NAT 网关。
2. **安全组出方向有没有放行？** 至少放行 TCP 443 出方向。
3. **隧道有没有在运行？** 在 ECS 上执行 `devbridge show <隧道ID>`，Host Connection Count 应该 ≥ 1（`devbridge list` 只显示摘要，不含此字段）。

### Q: 重启 ECS 后还能连吗？

能。安装时已配置开机自启：
- **Linux**：systemd 服务 `devbridge-ssh.service`，开机自动启动
- **Windows**：计划任务 `DevBridge-SSH`，开机以 SYSTEM 身份自动启动

重启后等 10-30 秒，隧道自动重连，即可正常 SSH。

### Q: API Key 会泄露吗？

默认不会。API Key 使用 AES-256-GCM + PBKDF2 加密存储在本地配置文件中，加密密钥由机器 UUID 派生，换机器无法解密。

- Linux：`~/.huawei/devbridge/ssh-tunnel.conf`
- Windows：`%USERPROFILE%\.huawei\devbridge\ssh-tunnel.json`

如果使用了 `--plaintext`（Linux）或 `-PlainText`（Windows）选项，API Key 会以明文存储，仅靠文件权限保护。不推荐在生产环境使用。

### Q: 有什么配额限制？

DevBridge 隧道有以下配额限制：

| 项目 | 限制 |
|------|------|
| 最大隧道数 | 10 个 |
| 每隧道最大端口数 | 10 个 |
| 每隧道最大 Host 数 | 1 个 |
| 每月流量配额 | 50 GB |
| 最大带宽 | 5 MB/s |
| 每端口最大连接数 | 100 |
| 每端口每分钟最大 HTTP 请求 | 500 |

如果需要在多台 ECS 上批量部署，请注意隧道数量上限（默认 10 个）。可通过 `devbridge limits` 查看当前用量和配额重置时间。

### Q: 隧道过期了怎么办？

隧道默认有效期 720 小时（30 天），剩余不足 24 小时自动续期，无需人工干预。如果隧道被误删，wrapper 脚本会自动重建。

### Q: 如何卸载？

**Linux：**
```bash
systemctl stop devbridge-ssh.service
systemctl disable devbridge-ssh.service
rm -f /etc/systemd/system/devbridge-ssh.service
rm -rf ~/.huawei/devbridge/
devbridge delete <隧道ID>
```

**Windows（PowerShell 管理员）：**
```powershell
Stop-ScheduledTask -TaskName DevBridge-SSH
Unregister-ScheduledTask -TaskName DevBridge-SSH -Confirm:$false
Remove-Item -Recurse -Force "$env:USERPROFILE\.huawei\devbridge"
devbridge delete <隧道ID>
```


### Q: 想换一个用户的 API Key 重跑怎么办？

直接用新 key 重跑即可。脚本会检测到 key 变化，自动登出旧账号、用新 key 登录，并为新账号创建隧道。旧账号的隧道会保留（30 天后自动过期），如需立即清理请用旧账号登录后 `devbridge delete <旧隧道ID>`。

### Q: 换 key 出错了怎么回滚？

脚本每次落库前会自动备份旧配置到 `.bak` 文件。回滚方法：

**Linux：** `cp ~/.huawei/devbridge/ssh-tunnel.conf.bak ~/.huawei/devbridge/ssh-tunnel.conf`，然后用旧 key 重跑。

**Windows：** `Copy-Item "$env:USERPROFILE\.huawei\devbridge\ssh-tunnel.json.bak" "$env:USERPROFILE\.huawei\devbridge\ssh-tunnel.json" -Force`，然后用旧 key 重跑。
